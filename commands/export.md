---
description: "Export a site's boards as .excalidraw files"
argument-hint: "<id> [--out DIR]"
---
Arguments: $ARGUMENTS. Run `tempboard export <id> [--out DIR]` (if `tempboard` is not on PATH, use `python3 "${CLAUDE_PLUGIN_ROOT}/bin/tempboard"`). By default the files go to `tempboard-<id>/` in the current folder. Tell the user the paths of the files it created.
