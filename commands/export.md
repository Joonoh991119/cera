---
description: "Export a site's boards as .excalidraw files"
argument-hint: "<id> [--out DIR]"
---
Arguments: $ARGUMENTS. Run `cera export <id> [--out DIR]` (if `cera` is not on PATH, use `python3 "${CLAUDE_PLUGIN_ROOT}/bin/cera"`). By default the files go to `cera-<id>/` in the current folder. Tell the user the paths of the files it created.
